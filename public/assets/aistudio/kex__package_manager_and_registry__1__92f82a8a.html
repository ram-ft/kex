kex: our own package manager and registry.

KEX is an npm-compatible package manager with its own independent registry. Install existing npm packages today, and publish to the KEX Registry as it comes online.

Compatibility is proven, not claimed

Every npm feature gets a row in a parity checklist. Nothing is marked Compatible until automated tests show the behavior.

What’s inside the monorepo

Rust for the CLI and engine, TypeScript for registry and web. They talk through stable HTTP APIs and package formats.

Core data model
